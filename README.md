⏱️ Python Countdown Timer

About

A simple countdown timer developed using Python.

The program takes time in seconds from the user and displays a countdown in HH:MM:SS format.

Features

- Takes time input from the user
- Converts seconds into hours, minutes and seconds
- Displays a live countdown
- Shows a message when time is up

Technologies Used

- Python
- Time module

Concepts Learned

- Variables
- User input
- For loops
- Modulus operator (%)
- Type conversion
- F-strings
- time.sleep()

How to Run

python countdown_timer.py
